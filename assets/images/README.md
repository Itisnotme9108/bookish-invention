# Editorial Resort & Swimwear — Image Asset Guidelines

All image placeholders are rendered as lightweight vector SVG graphics.

## Photography Specs
- **Lookbook Hero**: 1600x900px (16:9 ratio)
- **Product Cards**: 600x800px (3:4 portrait ratio)
- **Category Tiles**: 400x500px (4:5 portrait ratio)
- **Collection Banners**: 800x600px (4:3 ratio)
- **UGC Try-On Photos**: 500x500px (1:1 square ratio)
